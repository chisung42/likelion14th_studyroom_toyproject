비밀번호 해싱과 JWT 발급 로직을 추가합니다.

from passlib.context import CryptContext
from jose import jwt

pwd_ctx = CryptContext(
  schemes=["bcrypt"]
)

# 회원가입: 평문 → 해시
pwd_ctx.hash(request.password)

# 로그인: 평문 비교 → verify
pwd_ctx.verify(plain, hashed)

# 로그인 성공 시 JWT 발급
payload = {
  "sub": user.id,
  "role": user.role,
  "exp": ... (만료 시각)
}
jwt.encode(payload, SECRET_KEY)
🔑
dependencies.py 신규
app/dependencies.py

토큰을 검증하고 현재 유저를 꺼내는 공용 의존성입니다. 모든 보호된 라우터가 이걸 가져다 씁니다.

from fastapi.security import OAuth2PasswordBearer
from jose import jwt, JWTError

oauth2_scheme = OAuth2PasswordBearer(
  tokenUrl="/api/v1/auth/login"
)

def get_current_user(
  token: str = Depends(oauth2_scheme),
  db: Session = Depends(get_db)
) -> User:
  payload = jwt.decode(token, SECRET_KEY)
  user_id = payload["sub"]
  return user_repo.get_user(db, user_id)

posts / comments / reservations / rooms

쿼리 파라미터 user_id를 제거하고 의존성으로 교체합니다.

# Before
def create_post(
  user_id: int,  # ?user_id=1
  ...
):

# After
def create_post(
  current_user: User =
    Depends(get_current_user),
  ...
):

3 요청 흐름 비교

Phase 1 — 인증 없음
POST /posts?user_id=1
Content-Type: application/json

{
  "title": "제목",
  "content": "내용"
}

→ user_id=1 을 믿고 저장
→ 누구나 ?user_id=2 로 타인 행세 가능
Phase 2+4 — JWT 인증
POST /posts
Authorization: Bearer eyJhbGci...
Content-Type: application/json

{
  "title": "제목",
  "content": "내용"
}

→ 토큰 검증 → user_id 자동 추출
→ 위조 불가 (서버 서명 확인)
